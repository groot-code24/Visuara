# Implementation ledger

Statuses: `NOT_STARTED`, `IN_PROGRESS`, `BLOCKED`, `IMPLEMENTED`, `TESTED`, `VERIFIED`, `ACCEPTED`. `IMPLEMENTED` is not `VERIFIED`: a task is `VERIFIED` only when its acceptance criteria have passed, with the evidence linked.

In this ledger:
- **`TESTED`:** its automated tests pass on SQLite and PostgreSQL.
- **`VERIFIED`:** it is also tested, and its real runtime behaviour was exercised end to end. That means the browser walks in [END_TO_END_TEST_REPORT.md](../qa/END_TO_END_TEST_REPORT.md), or the backend end-to-end test where there is no user interface.
- **`ACCEPTED`:** needs the owner's acceptance, and is not used yet.

Nothing here is verified on the live Vercel deployment, which does not start (B-2).
