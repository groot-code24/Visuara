## User journeys found
Same-organization brand ↔ creator: invite, upload, analyse, place (overlay or tracked planar), quality check, fit review, propose, consent, approve, render, download, revise, revoke. Tracked links and manual conversion imports. **Not present at V6:** separate brand and creator organizations, a marketplace, campaigns, deals, 3D, colour integration, signed links, backups.

## Defects and gaps found during V8 work (all with regression tests)
| # | Severity | Finding | Fix |
|---|---|---|---|
| B1 | High | Dependencies with known advisories, including Pillow (parses untrusted uploads). | FastAPI 0.162 / Starlette 1.7 / pytest 9.2 installed and tested. Pillow 13 pinned for Python ≥ 3.11 (Docker image); **the local Python 3.10 venv cannot install it (blocker)**. |
| B2 | High | Planar tracker drifts under large viewpoint change (up to 5.7 px on a 25° orbit). | Reference-anchored ECC refinement per frame: max 0.82 px. |
| B3 | High | Focal-length confidence from calibration residuals was falsely tight on a degenerate (top-down) shot, giving a 20% error accepted by the 3D gate on dev data. | Direct observability test (reprojection sensitivity to ±15% focal). |
| B4 | High | A backup of a missing database silently produced an empty backup (`sqlite3.connect` creates files). | Backup refuses missing databases; opens read-only. |
| B5 | Medium | New marketplace listings defaulted to "not listed" in the UI. | Found by browser QA; default fixed. |
| B6 | Medium | Licensed videos did not appear in the brand's library, so they could not be placed from the UI. | Found by browser QA; `/api/videos` includes active grants. |
| B7 | Medium | Straight-alpha compositing darkened transparent edges (minimum 224 on white). | Premultiplied linear-light compositing (minimum ≥ 250). |
| B8 | Low | Full-frame ECC cost 0.7 s/frame. | Equal-size cropped ECC: ~0.08 s/frame. |
